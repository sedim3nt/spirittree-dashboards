# SpiritTree Dashboards

A collection of data visualizations exploring AI displacement, economic debasement, and the agent economy.

**Live:** [dashboards.spirittree.dev](https://dashboards.spirittree.dev)
**Stack:** Vite + React, TailwindCSS, Framer Motion
**Status:** Active

## What This Is

SpiritTree Dashboards is a tabbed collection of interactive data visualizations — each one telling a different story about AI's impact on work, money, and power. Think Bloomberg Terminal meets protest art: rigorous data, strong point of view.

Each tab is a standalone visualization that can be lazy-loaded. The collection includes Thought Clock (AI processing speed vs human cognition), Displacement Index (job risk tracking), Last Worker (automation timeline), Sørn's Law (marginal cost of intelligence), AI Pulse, Arms Race, Debasement, Agent Economy, Multiplier Effect, and Singularity Clock.

## Features

- 🧠 **Thought Clock** — real-time AI vs human cognitive speed comparison
- 💎 **Displacement Index** — industry-level job displacement risk
- ⏳ **Last Worker** — timeline to full automation scenarios
- 📉 **Sørn's Law** — declining marginal cost of intelligence
- 💜 **AI Pulse** — AI capability growth tracking
- ⚔️ **Arms Race** — AI investment and competition data
- 🪙 **Debasement** — currency and purchasing power erosion
- 🤖 **Agent Economy** — autonomous agent market metrics
- 🚀 **Multiplier** — AI productivity multiplier calculations
- 🕛 **Singularity Clock** — countdown-style capability tracker
- 🔀 **Tabbed Navigation** — color-coded tabs with lazy-loaded content
